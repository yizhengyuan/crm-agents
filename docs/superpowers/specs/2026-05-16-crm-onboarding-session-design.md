# CRM 客户知识库 · 业务团队导入培训方案

日期：2026-05-16
阶段：Brainstorming / 培训设计
状态：已确认

## 1. 背景与目标

2026-05-17 上午，向业务团队（非技术背景）介绍 CRM 客户知识库系统，并带领团队实际操作使用。

- 时长：3-4 小时（计划约 3 小时，预留缓冲）
- 听众：业务团队
- 核心目标：让团队理解工具价值和完整工作流

## 2. 培训节奏：混合方案 C

讲一段 → 跟一段 → 小结一段。4 个递进环节 + 收尾，每节包含「你先演示 → 他们动手 → 小结价值」。

## 3. 环节设计

### 环节 1｜现在怎么做，问题在哪（30 min）

**目标：** 建立普遍认知——当前客户管理方式的痛点和新工具的定位。

| 分钟 | 内容 |
|------|------|
| 0-10 | **引子**：讲一个真实痛点——客户信息散落在微信聊天、截图、脑子里，想不起来上次这人聊了什么 |
| 10-20 | **愿景**：如果每个客户都有一个"活档案"，资料自动汇总，AI 帮你理解客户——这是我们要做的事 |
| 20-30 | **闭环介绍**：资料沉淀 → AI 理解 → 人工确认 → 持续更新。强调：AI 是助手，人是决策者 |

不需要系统运行，纯讲解。

### 环节 2｜建立客户档案（40 min）

**目标：** 每人完成 2-3 个客户档案的建立，体验统一档案的价值。

| 分钟 | 内容 |
|------|------|
| 0-10 | **你演示**：新建一个真实客户，填基础信息（姓名、微信、公司、备注），展示客户列表 |
| 10-30 | **他们动手**：每人建 2-3 个自己的客户。只要求姓名 + 一两行备注，降低建档门槛 |
| 30-40 | **小结**：统一客户档案的价值——不再翻聊天记录找信息了 |

**依赖功能：** 客户列表页 + 新建客户页面

### 环节 3｜沉淀资料，让 AI 读懂客户（40 min）

**目标：** 每人给自己建档的客户添加 2-3 条资料，体验时间线视图。

| 分钟 | 内容 |
|------|------|
| 0-10 | **你演示**：给客户添加资料——手动记录一段对话摘要、粘贴一段真实微信聊天文字、上传一张聊天截图 |
| 10-30 | **他们动手**：给自己建的客户添加 2-3 条资料，至少包含一段聊天文字和一张截图 |
| 30-40 | **小结**：时间线把零散信息变成客户故事。截图会被 OCR 识别，AI 能"看懂"聊天内容 |

**依赖功能：** 材料录入（文字 + 截图上传）+ 客户时间线

### 环节 4｜AI 给出建议，人工确认标签（40 min）

**目标：** 每人触发一次 AI 分析，体验从 AI 建议到人工确认的完整决策流程。

| 分钟 | 内容 |
|------|------|
| 0-10 | **你演示**：触发 AI 分析，展示 AI 输出——客户一句话摘要、分层建议 + 理由、阶段建议 + 理由、风险信号 |
| 10-25 | **他们动手**：给自己的客户触发 AI 分析，看 AI 怎么理解自己的客户 |
| 25-35 | **关键操作**：人工确认分层/阶段——同意则确认，不同意则手动选择并说明原因 |
| 35-40 | **小结**：AI 不替你做决策，但帮你省掉 80% 的整理和判断时间 |

**依赖功能：** AI 分析服务 + 分析面板 + 标签确认

### 收尾｜闭环回顾 + 反馈（20 min）

**目标：** 串联全流程，收集反馈，明确下一步。

| 分钟 | 内容 |
|------|------|
| 0-5 | 回顾今天的完整闭环：建档 → 加资料 → AI 分析 → 确认标签 |
| 5-15 | 收集反馈：AI 建议准不准？哪里觉得有用？哪里不理解？缺什么？ |
| 15-20 | 讲下一步：团队协作、AI 每日行动推荐、微信自动同步等未来方向 |

## 4. 关键信息点（每个环节必须传达）

- AI 是助手，不是决策者。所有标签由人工最终确认
- 客户资料越多，AI 判断越准。资料不足时 AI 会诚实说"信息不足"
- 每条 AI 分析保存历史版本，可追溯可对比
- 分层（S/A/B/C/D）和分阶（6 阶段）是固定的，但判断标准可编辑可优化

## 5. 环境与准备工作

### 5.1 提前准备

- 系统需部署到可访问地址（或本地服务 + 每人可访问的局域网地址）
- 准备 1-2 个"演示用客户"的完整资料，确保演示环节流畅
- 准备一份简单的操作指引（图文，A4 一页）
- 确保每人有独立的账号或至少独立的客户隔离

### 5.2 降级方案

如果某个功能未就绪：

- 环节 2 不可用：展示设计稿 + 先跳过，直接进入环节 1 之后的环节 3
- 环节 3 不可用：展示材料录入的设计稿 + 数据流图示
- 环节 4 不可用：展示 AI 分析原型 + 预设一份 AI 分析结果示例

### 5.3 反馈收集要点

- 哪一步最顺？哪一步最卡？
- AI 建议和你的判断一致吗？不一致的地方在哪里？
- 还缺什么信息/功能让你觉得"不好用"？
- 你觉得这个工具能替代你现在的什么操作？

## 6. 当前确认结论

- 培训节奏采用方案 C（混合节奏）
- 核心目标是"理解价值和流程"
- 先相信智能体能完成全功能开发，按全功能设计
- 同步准备各环节的降级方案
- 环节以真实业务客户数据为操作对象
