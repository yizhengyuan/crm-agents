# CRM 客户知识库前端 UI 设计与组件文档

日期：2026-05-16
阶段：UI 设计规范
状态：供前端开发参考

---

## 1. 设计目标

- 打造一个高级、清晰、可操作的客户工作台
- 核心目标：

  - 客户资料沉淀（文字、截图、附件、OCR）
  - AI 客户理解（摘要、核心需求、分层分阶建议、风险信号）
  - 人工确认保持业务判断权
- UI 风格：干净、留白充足、圆角卡片、柔和色彩
- 技术栈：Next.js + React + Tailwind CSS + shadcn/ui + Framer Motion

---

## 2. 整体布局

### 三栏设计（客户详情页核心页面）

| 栏位  | 内容                   | 比例     | 备注                            |
| --- | -------------------- | ------ | ----------------------------- |
| 左栏  | 客户画像 + 今日概览 + AI 小助手 | 20–25% | 左栏固定，滚动时间线时保持可见               |
| 中间栏 | 资料时间线                | 50–55% | 手动记录、聊天记录、OCR、附件              |
| 右栏  | AI 客户理解              | 20–25% | 摘要、核心需求、分层/分阶建议、风险信号、缺失信息，可折叠 |

---

## 3. 左栏组件拆解

### 客户信息卡片

- **内容**：

  - 头像 + 姓名（18px, 中粗）
  - 微信号、出生日期（14px）
  - 当前分层 S/A/B/C/D（深绿色/蓝色/紫色/灰蓝/灰色）
  - 当前阶段分阶（蓝色 Badge）
  - 价值标签（绿色 Badge）
  - 公司/行业/角色/城市
  - 客户来源、首次添加、最近互动时间
  - 资料数量
  - 人工确认状态（已确认 / 待确认）
  - 风险信号（红色 Badge）
  - 备注（可编辑文本）

- **视觉**：

  - 卡片白底、圆角 2xl、轻阴影、内边距 24px
  - 留白充足，分组清晰

### 今日概览

- 客户总数、S/A 客户数、待分析客户、今日新增资料
- +/- 增量标识（绿色正增，红色负增）

### AI 小助手提示

- 提示信息："去添加资料"等
- 卡片化、圆角、浅紫蓝背景
- 行动按钮可触发操作

---

## 4. 中间栏组件拆解

### 资料时间线

| 类型     | 标识                 | 备注          |
| ------ | ------------------ | ----------- |
| 聊天记录   | 绿色小点 + 文本          | hover 提示可编辑 |
| OCR 截图 | 蓝色小点 + 图片缩略图       | 点击可查看原图     |
| 手动记录   | 橙色小点 + 文本          | 可折叠长文本      |
| 附件     | 紫色小点 + 图标 + 文件名/大小 | 点击下载或查看     |

- Tabs / 筛选：全部 / 手动记录 / 聊天记录 / OCR / 附件
- 可按类型或日期折叠
- 点击展开全文或附件 Modal
- hover 提示可操作
- 添加资料按钮固定底部
- 骨架屏：AI 分析或 OCR 加载时显示占位 Skeleton

---

## 5. 右栏组件拆解（AI 客户理解）

| 卡片类型   | 内容               | 样式/颜色      |
| ------ | ---------------- | ---------- |
| 一句话摘要  | 客户核心情况           | 白卡片、轻阴影    |
| 核心需求   | 列表化显示关键需求        | 绿色卡片、图标    |
| 画像信号   | 用户偏好、行为特征        | 浅绿卡片       |
| 付费能力信号 | 门店数量、系统投入        | 紫色卡片       |
| 分层建议   | S/A/B/C/D + 理由文本 | 金色/蓝色卡片    |
| 分阶建议   | 阶段 1–6 + 当前阶段    | 蓝色卡片       |
| 风险信号   | 决策风险、价格敏感        | 红色卡片       |
| 缺失信息   | 待收集资料或关键信息       | 橙色卡片       |
| AI 建议  | 后续操作推荐           | 紫蓝渐变卡片     |
| 操作按钮   | 重新分析             | 蓝色按钮，圆角 lg |

- 动效：卡片折叠/展开，AI 重新分析加载 Skeleton

## 6. 颜色规范

| 用途         | 色彩       |
| ---------- | -------- |
| 分层 S       | 深绿色      |
| 分层 A       | 蓝色       |
| 分层 B       | 紫色       |
| 分层 C       | 灰蓝       |
| 分层 D       | 灰色       |
| 风险         | 红色       |
| 缺失信息       | 橙色       |
| AI 建议      | 紫蓝渐变     |
| 背景         | 浅灰 / 白卡片 |
| 按钮 / Badge | 主色蓝紫     |

---

## 7. 字体与留白

- 标题：18–24px，中粗
- 正文：14–16px
- Badge / 标签：12–14px
- 页面内边距：24–32px
- 卡片间距：16–24px
- 卡片内部 padding：20–24px
- 圆角：卡片 2xl / 按钮 lg / Badge full

---

## 8. 交互设计

- 时间线滚动时左栏客户信息固定
- hover 卡片阴影提示可点击
- AI 面板可折叠/展开
- 空状态提示：无资料或 AI 输出为空时显示操作指引
- 上传附件 / OCR 提示加载状态
- 点击附件或截图弹出 Modal

---

## 9. 组件映射表

| 组件             | Tailwind / shadcn/ui 类                                        | 功能              |
| -------------- | ------------------------------------------------------------- | --------------- |
| Card           | bg-white shadow-md rounded-2xl p-6 mb-4                       | 客户信息、资料、AI 输出   |
| Badge          | rounded-full px-3 py-1 text-sm + 颜色                           | 分层/分阶/风险/缺失信息   |
| Button         | rounded-lg px-4 py-2 bg-blue-600 text-white hover:bg-blue-700 | 人工确认、重新分析、上传资料  |
| Input/Textarea | shadcn/ui Input + Tailwind forms                              | 新建客户、备注         |
| Tabs/Accordion | shadcn/ui Tabs / Accordion                                    | 资料时间线分组         |
| Skeleton       | shadcn/ui Skeleton                                            | AI 分析或 OCR 加载占位 |
| Modal/Dialog   | shadcn/ui Dialog + rounded-2xl                                | 查看附件 / 编辑资料     |
| Icon           | lucide-react                                                  | 资料类型 / 状态标识     |

---

## 10. 优化点

1. 三栏比例自适应，右栏 AI 面板可折叠
2. 时间线按日期/类型折叠，颜色区分资料类型
3. AI 输出卡片化，信息层级清晰
4. 统一颜色、圆角、留白、字体
5. 骨架屏和空状态提示提高用户感知
6. 滚动时固定左侧客户画像
7. 动效统一，保证高级感

## 11. 前端目录结构示意

```
/pages
  index.tsx           # 客户列表页
  customer/[id].tsx   # 客户详情页
  new-customer.tsx    # 新建客户页
  tags.tsx            # 标签管理页

/components
  Card.tsx
  Badge.tsx
  Button.tsx
  Tabs.tsx
  Accordion.tsx
  Skeleton.tsx
  Modal.tsx
  TimelineItem.tsx
  AIAnalysisCard.tsx
```

- 页面文件对应核心页面
- 组件可复用，保持风格一致
- Tailwind + shadcn/ui 样式统一

---

## 12. 落地建议

1. 先开发核心页面：客户详情页 → 客户列表页 → 新建客户页 → 标签管理页
2. 组件复用：Card、Badge、Button、Tabs、Modal、Skeleton、TimelineItem、AIAnalysisCard
3. 统一视觉规范：颜色、字体、圆角、留白
4. 交互细节：滚动固定、折叠面板、骨架屏、空状态提示
5. 动效统一：卡片折叠/展开、加载占位动画
